Install

Up and running in a minute

Needs Windows 10 or 11.

Download

Grab lyrics-overlay.exe from the latest release.

Pick a folder

Keep it somewhere you can write to, like %LOCALAPPDATA%\Programs\Lyrics Overlay, so it can update itself.

Run it

Double-click, then play a song. Right-click the exe → Pin to Start to find it later.

The app isn't code-signed yet, so Windows may show "Windows protected your PC". Click More info → Run anyway. To remove it, quit from the tray icon and delete the file.

Shortcuts

Ctrl Alt LShow or hide lyrics
Ctrl Alt SSync: press the moment the line on screen is sung
Ctrl Alt ↑ / ↓Lyrics earlier / later by 0.25 s
Ctrl Alt O / PNext / previous lyrics version
Ctrl Alt MArrange: drag and resize the card and the lyrics
Right-click the cardHide it to click what's under it
Privacy

No account. No tracking.

The app only talks to the services it needs to find lyrics and covers.

LRCLIB & NetEaseSong title, artist and length, to find lyrics.
iTunesTitle and artist, to find a cover when the player shares none.
ShazamAn audio fingerprint (not the audio) of ~11 s, only when song recognition is on and no lyrics were found.
GitHubOnce a day, which version is newest, only when Check for updates is on.
